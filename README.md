# Proyecto Cine – Lenguaje C

Proyecto académico desarrollado en Lenguaje C como parte de la materia Programación
de la Licenciatura en Sistemas (Universidad Nacional de Lanús).

## Descripción
Sistema de gestión de cine que permite administrar películas, funciones y reservas,
aplicando estructuras de datos, control de flujo y modularización del código.

## Tecnologías
- Lenguaje C
- Archivos
- Estructuras (struct)

## Trabajo en equipo
Este proyecto fue desarrollado de forma grupal.
Cada integrante trabajó en su propia rama, que luego fue integrada a la rama principal (`main`).

La rama `main` contiene la versión final del proyecto.

## Contexto académico
Proyecto evaluado y aprobado con calificación 9.
